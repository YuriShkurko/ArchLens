# ArchLens v0.2.2 release notes draft

## Focus

v0.2.2 is an external usability and installability hardening release. It makes ArchLens easier for another developer to clone, build, link locally, package-smoke-test, and run on their own repository without hand-holding.

## What changed

- Clarified package metadata for root, CLI, and core packages.
- Kept the CLI bin as `archlens`.
- Added package `files` entries so packed packages contain the built output and package metadata.
- Documented a tested local `npm link` flow for global-style usage.
- Improved CLI help for:
  - `archlens --help`
  - `archlens snapshot --help`
  - `archlens diff --help`
  - `archlens render --help`
- Made `diff` explicitly require `--base` and `--head` so first-time usage is clear.
- Improved first-time-user errors for:
  - not being inside a git repository;
  - missing/unresolvable refs;
  - missing git on `PATH`;
  - running `render` before `diff`.
- Added `docs/usage.md` with practical install/build/link/pack instructions and common fixes.
- Added `scripts/smoke-pack.sh` to pack `@archlens/core` and `@archlens/cli`, install them into a temporary git repo, and run the packaged CLI end to end.
- Updated README with a short “Try it locally” path and a link to usage docs.

## What v0.2.2 does not add

- No AI inference.
- No GitHub App support.
- No SaaS, dashboard, database, auth, or MCP.
- No plugin framework.
- No new language analyzers.
- No FastAPI route intelligence.
- No deep symbol graph or call graph.
- No npm publish.

## How to test locally

From the ArchLens checkout:

```bash
pnpm install
pnpm typecheck
pnpm build
pnpm test
```

Run CLI help:

```bash
pnpm archlens -- --help
pnpm archlens -- snapshot --help
pnpm archlens -- diff --help
pnpm archlens -- render --help
```

Run the package smoke test:

```bash
scripts/smoke-pack.sh
```

Link the CLI locally if desired:

```bash
cd apps/cli
npm link
archlens --help
```

Try on another local repo:

```bash
cd /path/to/other/repo
archlens snapshot
archlens diff --base HEAD~1 --head HEAD
archlens render --mode pr
```

If the CLI is not linked globally, use the built CLI directly:

```bash
node /path/to/ArchLens/apps/cli/dist/index.js snapshot
node /path/to/ArchLens/apps/cli/dist/index.js diff --base HEAD~1 --head HEAD
node /path/to/ArchLens/apps/cli/dist/index.js render --mode pr
```

## Known limitations

- ArchLens is not published to npm yet.
- TypeScript/JavaScript and Python are the only supported analyzer facts in v0.2.x.
- Python support remains deterministic and limited: no dynamic/runtime import resolution, no type analysis, no symbol/call graph, no namespace package completeness, and no FastAPI route intelligence.
- TypeScript path aliases and non-relative imports may be unresolved.
- Risk signals and related-test suggestions are deterministic heuristics, not proof of bugs or coverage.

## Dogfood context

v0.2.1 is the analyzer-quality baseline for this release:

- AIJobRadar mixed FastAPI/Python + React dogfood reached 4.7 / 5 overall usefulness with a 4 / 5 PR paste score.
- AgentForge Python-heavy dogfood reached 4.3 / 5 and found a Python scanner false-positive class that v0.2.1 fixed.
- Typecheck, build, tests, and real-repo snapshot/diff/render flows passed before this external usability pass.
